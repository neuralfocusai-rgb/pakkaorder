# PakkaOrder

**Ship only pakka orders.**

PakkaOrder is a WhatsApp-first COD confirmation shield for India and
COD-first Asia. Before a brand ships a cash-on-delivery order, the buyer
gets a 10-second vernacular confirmation page to re-confirm address and
intent with one tap: "Haan, pakka."

Every order comes back scored: confirmed, risky, or fake.

## The problem
- 25-40% of COD orders in India return undelivered (RTO)
- Each RTO costs brands Rs 100-250 in logistics plus dead stock
- COD is still 30-60% of orders across Bharat (tier 2/3, fashion, electronics)

## The product
- Buyer confirmation page in Hindi, Tamil, Telugu, Bengali + English
- One-tap confirm, no app, no login
- Order risk scoring from confirmation telemetry
- Pay-per-use credits (Rs 1.5 per verification) for the long tail of sellers
- Roadmap: missed-call confirmation, WhatsApp Cloud API, SMS fallback

## Status
Pre-launch. Core schema and secure write paths in progress.
